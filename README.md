# 個人專屬 AI 投資資訊站 (AI Stock Investment Station)

整合「個人持股倉・鎖單股追蹤・三大法人・400/1000張大戶・董監內部人・CB可轉債與財報營收資料庫系統」。

---

## 檔案結構說明

| 檔案名稱 | 說明 |
| :--- | :--- |
| **`index.html`** | 完整前端系統（支援智慧 CSV 匯入、即時報價更新、Dark Mode、Tailwind CSS、Chart.js 圖表）。直接用瀏覽器開啟即可使用。 |
| **`tw_stock_data_engine.py`** | 官方 OpenAPI 與即時行情抓取引擎（支援上市 TWSE + 上櫃 TPEx、MIS 即時盤中報價、TDCC 集保大戶分級運算、MOPS 月營收與財報）。 |
| **`stock_template_sample.csv`** | 標準 UTF-8 with BOM 匯入範本檔，亦相容各券商（如元大、永豐、國泰、富邦）庫存損益匯出檔案。 |

## 核心改善與即時正確資訊獲取架構

### 1. 檔案匯入機制改善（Smart CSV Engine）
- **RFC 4180 標準解析**：支援研究備註中的引號、逗號與多行換行。
- **BOM 智慧去除**：徹底解決 Excel 匯出檔前綴 `\uFEFF` 導致代號配對失敗問題。
- **模糊標頭自動對齊 (Fuzzy Header Mapping)**：不論是「證券代號」、「股票代號」或「庫存股數」、「張數」，系統皆能自動映射，支援只有「代號、成本、股數」的簡易券商庫存檔。
- **動態生成歷史基準**：匯入新標的時，依最新指標動態生成合理趨勢，避免複製舊有標的（如台光電）之假資料。

### 2. 即時正確資訊獲取方案（TWSE / TPEx / TDCC / MOPS）
- **盤中即時報價（9:00 - 13:30）**：對接證交所市況報導 `mis.twse.com.tw`（支援 `tse_xxx` 與 `otc_xxx`）。
- **集保 400/1000張大戶（每週五 19:00）**：集保開放資料 `1-4` 級距自動統計（級距 12~15 為 400張以上，級距 15 為 1000張以上）。
- **月營收與季財報**：MOPS 官方開放資料端點自動計算 YoY、MoM 與 EPS。

## 快速使用指南

1. **直接使用網頁**：
   雙擊開啟 `index.html` 即可於瀏覽器操作，點擊右上角「⚡ 更新最新報價」或「📥 智慧匯入 / 匯出」。
2. **本機全量數據校驗（推薦）**：
   執行指令：
   ```bash
   python tw_stock_data_engine.py
   ```
   將自動生成最新盤後/盤中數據 `portfolio_latest.csv` 與 `stock_database.json`，於網頁 View 4 點擊匯入即可 100% 同步真實市場大戶與營收。
